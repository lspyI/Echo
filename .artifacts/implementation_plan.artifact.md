# Исправление отзывчивости и логики Режима Невидимка (v28)

Этот план направлен на устранение проблем с нажатием кнопки "Режим Невидимка" и предотвращение блокировки интерфейса.

## User Review Required

> [!IMPORTANT]
> Мы меняем логику: тумблер теперь будет переключаться **мгновенно**. Если разрешение на камеру не будет получено, он автоматически вернется в положение "выкл" через секунду с пояснением.
> Защитный экран (размытие при посторонних) теперь будет активен **только если приложение открыто полностью** и не будет перекрывать настройки.

## Verification Plan

### Manual Verification
- **Click Test**: Зайти в настройки -> нажать на тумблер. Он должен переместиться мгновенно.
- **Permission Flow**:
    1. Нажать "Вкл".
    2. Если разрешения нет -> появится окно Android.
    3. Нажать "Запретить" -> тумблер должен сам вернуться в "Выкл".
    4. Нажать "Разрешить" -> тумблер остается "Вкл", загорается индикатор камеры.
- **Intruder Test**: Включить режим -> выйти на главный экран -> позвать друга. Экран должен размыться.
