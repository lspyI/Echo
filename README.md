# Echo

**Echo** — это высокотехнологичный голосовой ИИ-дневник, написанный на **Kotlin** с использованием **Jetpack Compose**. Приложение сочетает в себе премиальный дизайн в стиле Glassmorphism и мощные возможности современных нейросетей для анализа эмоционального состояния.

### Основные функции и технологии:
*   **ИИ-Терапевт (Gemini 3.6 Flash)**: Мультимодальный анализ ваших мыслей, автоматическое выделение тегов и эмпатичные ответы на русском языке.
*   **Персонализация ИИ**: Выбор из 6 личностей (Психолог, Друг, Любящая девушка, Философ, Строгий коуч, Дзен-мастер).
*   **Liquid Glass UI**: Уникальный интерфейс с использованием AGSL-шейдеров, динамических градиентов и эффекта "живого стекла".
*   **AI Stealth Mode**: Революционная функция приватности — приложение использует ML Kit Face Detection, чтобы мгновенно размыть экран, если фронтальная камера заметит постороннего человека, заглядывающего через плечо.
*   **Музыкальное настроение**: Интеграция с Spotify, Яндекс Музыкой и Apple Music — ИИ подбирает треки под ваше текущее состояние.
*   **Безопасность**: Двухуровневая защита (Biometric Prompt + зашифрованный PIN-код).
*   **Аналитика и Календарь**: Визуализация настроения за месяц и еженедельные текстовые отчеты от ИИ.
*   **Виджеты (Glance)**: Быстрая запись и "Инсайт дня" прямо на рабочем столе.

### Технический стек:
`Kotlin`, `Jetpack Compose`, `Material 3`, `Room DB`, `Hilt (DI)`, `Google Gemini AI`, `CameraX`, `ML Kit`, `DataStore`, `Media3 (ExoPlayer)`, `AGSL Shaders`.

### Как запустить проект:
1.  Получите бесплатный API ключ в [Google AI Studio](https://aistudio.google.com/).
2.  Откройте файл `app/src/main/java/com/example/echojournal/data/remote/GeminiClient.kt`.
3.  Найдите строку `private var apiKey: String = "YOUR_GEMINI_API_KEY_HERE"` и вставьте ваш ключ.
4.  Соберите проект в Android Studio (требуется версия Ladybug или новее).

У проекта открытый код, и каждый разработчик может изучить его структуру. Код написан по стандартам MVVM, снабжен пояснениями и является отличным примером интеграции передовых ИИ-технологий в мобильное приложение.
